# Bé Vui Học Chữ – Cô Thới Thị Non

Gói này đã sẵn sàng cho **GitHub Pages**.

## Cách đưa lên GitHub

1. Giải nén file ZIP.
2. Tạo một repository mới trên GitHub.
3. Tải **toàn bộ nội dung bên trong thư mục đã giải nén** lên thư mục gốc của repository, gồm `index.html`, thư mục `assets` và file `README.md`.
4. Vào **Settings → Pages**.
5. Chọn **Deploy from a branch** → chọn nhánh `main` → thư mục `/(root)` → **Save**.
6. Chờ GitHub Pages tạo đường dẫn website rồi mở đường dẫn đó để sử dụng.

Không đổi tên hoặc tách rời thư mục `assets`, vì toàn bộ tranh minh họa, nhạc và học liệu đang được liên kết từ thư mục này.
